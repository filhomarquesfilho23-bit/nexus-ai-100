# NEXUS IA 100
## Plataforma de 100 Agentes de IA

---

Esta é a aplicação oficial do **NEXUS IA 100**, uma plataforma com 100 ferramentas e agentes de Inteligência Artificial, integração com API Gemini, monetização e compilação para Android.

### Estrutura e Módulos
* **NEXUS CORE:** Motor principal e orquestração com API Gemini.
* **NEXUS AGENTS:** Catálogo de 100 agentes e ferramentas de IA.
* **NEXUS STUDIO:** Interface web e aplicação Android.

### Ficheiros do Repositório
* `index.html` e `script.js`: Interface e lógica principal da aplicação web.
* `banner.html`: Bloco HTML de banner.
* `package.json`: Dependências e scripts do projeto.
* `.github/fluxos de trabalho`: Automação e compilação via GitHub Actions.
